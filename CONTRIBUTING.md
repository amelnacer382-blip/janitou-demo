# JANITOU FOOD — Contribution Rules

## 1. Repository Ownership
The repository is owned and controlled by JANITOU FOOD.

## 2. Access and Security
- Each contributor must use their own GitHub account.
- Never share passwords or authentication codes.
- Access is granted only to authorized contributors.
- The repository owner controls access permissions.

## 3. Development Rules
- Keep all application source code in this repository.
- Use clear and meaningful commit messages.
- Do not delete or overwrite existing work without authorization.
- Do not add passwords, API keys, or other secrets to the repository.
- Keep project specifications and business decisions in Google Drive.

## 4. Changes and Approval
- Explain significant changes before implementing them.
- Confirm requirements and acceptance criteria before developing major features.
- Test changes before considering them complete.
- Document important technical decisions.

## 5. Project Handover
The development team must keep the source code organized and ensure that JANITOU FOOD can access the project files and development history.
