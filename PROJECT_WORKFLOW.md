# JANITOU FOOD — Project Workflow

## Project Documentation
Google Drive is the primary location for project specifications, decisions, requirements, meeting notes, and business documents.

## Source Code
GitHub is the official repository for application source code and technical development history.

## Repository Ownership
The repository is owned and controlled by JANITOU FOOD. Access is granted individually to authorized project contributors.

## Development Rules
- Keep project decisions and specifications in Google Drive.
- Keep application source code and code-related changes in GitHub.
- Avoid unnecessary duplication of documents.
- Record important development changes through Git commits.
- Confirm requirements and acceptance criteria before implementing major features.
